# Generator: パターン検出と適合

本ファイルは `generator` / `team-generator` が起動直後に `Read` する。**この内容は agent .md 側に絶対に inline でコピーしない**。

## パターン検出と適合

実装前に既存コードベースを調査し、以下の規約を検出して適合する。

- **命名規約**: 変数・関数・ファイル名の命名スタイル（camelCase / kebab-case 等）
- **ディレクトリ構造**: ファイルの配置場所・モジュール境界
- **テストパターン**: describe/it の構成・モックの方法・アサーションスタイル
- **インポートスタイル**: 絶対パス / 相対パスの使い分け

新規コードは既存パターンに従う。既存パターンが存在しない場合は最も近い慣用的なスタイルを選択する。
