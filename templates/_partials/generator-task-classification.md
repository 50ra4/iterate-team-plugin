# Generator: タスク分類と探索深度

本ファイルは `generator` / `team-generator` が起動直後に `Read` する。**この内容は agent .md 側に絶対に inline でコピーしない**。

## タスク分類と探索深度

実装前にタスクを以下の 3 段階に分類し、探索深度と検証粒度を比例させる。

| 分類        | 目安                                       | 探索深度                                  | 検証粒度                         |
| ----------- | ------------------------------------------ | ----------------------------------------- | -------------------------------- |
| **Trivial** | 1 ファイル・設定変更・typo 修正            | 変更対象ファイルのみ確認                  | lint のみ                        |
| **Scoped**  | 複数ファイル・既存機能の拡張               | 変更対象 + 直接依存ファイルを確認         | lint + 型チェック + 関連テスト   |
| **Complex** | 新規機能・インターフェース変更・横断的影響 | 関連モジュール全体 + テストパターンを確認 | lint + 型チェック + 全関連テスト |
